# AdrielOS — Portfólio Pessoal Interativo

> *"Entre códigos, ideias e futebol, estou sempre criando algo novo."*  
> — **Adriel Morback**

Bem-vindo ao **AdrielOS**, um portfólio interativo para web inspirado na experiência imersiva de sistemas operacionais modernos, desenvolvido com uma identidade visual própria e construído exclusivamente em **HTML5**, **CSS3** e **JavaScript Vanilla**.

---

## 🌟 Destaques do Projeto

- **Simulação Completa de Sistema Operacional no Navegador:**
  - Tela de carregamento (bootloader) estilizada com opção de pular.
  - Área de trabalho interativa com ícones selecionáveis (duplo clique no desktop, toque único no celular).
  - Gerenciador de janelas completo: arrastar, minimizar, maximizar, restaurar e fechar.
  - Barra de tarefas com relógio e data atualizados em tempo real, status e controle de som e tema.
  - Menu Iniciar com pesquisa instantânea em tempo real.
  - Menu de contexto (botão direito) no desktop.
- **Identidade Visual Autoral:**
  - Paleta em tons escuros de ardósia e azul petróleo com acentos em verde neon (`#00ff88`) e ciano cibernético (`#38bdf8`).
  - União entre o universo do desenvolvimento de software e a paixão pelo futebol tático e de rua.
  - Múltiplos papéis de parede integrados e alternáveis com 1 clique.
- **Projetos Reais & Verificados:**
  - **BEIÇO STREET — Taça das Favelas Campinas:** Jogo de futebol de rua 1v1 arcade desenvolvido para o navegador em HTML5 Canvas e JS puro ([Repositório Oficial no GitHub](https://github.com/43111-cyber/jogo-ste)).
  - **Apostila de Excel para Idosos:** Material didático humanizado para inclusão digital e alfabetização tecnológica da terceira idade.
  - **Próximos Projetos:** Área dedicada para futuras ideias e sistemas em desenvolvimento.
- **100% Responsivo e Acessível:**
  - Otimizado tanto para telas grandes de computadores quanto para celulares e tablets.

## 🚀 Como Executar Localmente

Como o projeto é construído em código puro (sem necessidade de bundlers ou compilação), você pode abri-lo de maneira simples:

### Opção 1: Servidor Local via Python
```bash
python -m http.server 8080 --directory portfolio
```
Depois, abra seu navegador em `http://localhost:8080`.

### Opção 2: Servidor Local via Node
```bash
npx -y serve portfolio
```

### Opção 3: Abertura Direta
Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Firefox, Safari, Edge).
